# MiaoUILite

MiaoUILite - это облегчённая C++-библиотека для построения GUI на Windows. Она предоставляет DirectUI-подход, XML-описание интерфейсов и набор готовых контролов, которые можно встроить в собственные настольные приложения.

## ✨ Особенности

- Статическая библиотека GUI для Windows.
- XML-описание интерфейсов и layout.
- Набор базовых контролов: кнопки, списки, поля ввода, слайдеры, прогресс и другие.
- Отдельное тестовое приложение `MiaoUITest`.
- Утилита `DmResEditor` для работы с ресурсами формата DMResFile V1.

## 🚀 Быстрый старт

### Требования

- Visual Studio 2022
- MSVC `v143`
- Windows SDK
- C++17

### Сборка

1. Откройте `MiaoUILite.sln`.
2. Соберите проект `MiaoUILite` в нужной конфигурации.
3. Для проверки библиотеки запустите `MiaoUITest`.

По `MiaoUI\\MiaoUI.vcxproj` библиотека собирается как `StaticLibrary`, а артефакты складываются в `MiaoUI\\library\\`.

### Запуск

- Для проверки библиотеки соберите и запустите `MiaoUITest`.
- Для редактора ресурсов соберите и запустите `DmResEditor`.
- Для интеграции в свой проект подключите заголовки из `MiaoUI\\src\\include` и библиотеку из `MiaoUI\\library`.

## 📁 Структура проекта

- `MiaoUI/` - исходный код и заголовки библиотеки.
- `MiaoUITest/` - тестовое приложение для проверки библиотеки.
- `DmResEditor/` - редактор ресурсов.
- `bin/` - вспомогательные бинарные файлы.
- `MiaoUILite.sln` - solution Visual Studio.

## 🛠 Использование

Типовой сценарий:

1. Соберите `MiaoUILite`.
2. Запустите `MiaoUITest`, чтобы проверить рендер и поведение контролов.
3. Подключите библиотеку в своё приложение через include-пути и статическую линковку.

Интерфейсы описываются XML-разметкой, а доступные атрибуты и геометрия упоминаются в `AttribName.txt` и `GeometryXML.txt`.
